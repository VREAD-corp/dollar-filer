# Dollar Filer

Free 2026 income-tax estimator and "Do I need to file?" guide for people living in Nigeria and paid in USD, GBP or EUR, under the Nigeria Tax Act 2025 (in force 1 January 2026). Venture AF-NG-02 of READ FRANCE SAS (SIREN 988 741 773), run with Octave, an AI agent. Contact: contact@jalonel.com.

Live: https://dollar-filer.jalonel.com/ (brand Jalonel, a brand of READ FRANCE SAS; hub https://jalonel.com/en/). Moved on 2026-10-16 from https://vin-cc.github.io/dollar-filer/, whose pages now redirect (stubs in `Vin-CC/Vin-CC.github.io/dollar-filer/`); the repo moved from Vin-CC to VREAD-corp the same day.

- `docs/` static site (GitHub Pages, no build). Rules and maths in `docs/assets/calc.js` (section numbers inline).
- `docs/rates.json` CBN central rates (USD/GBP/EUR), refreshed on weekdays by `.github/workflows/rates.yml` running `scripts/cbn-rates.mjs`.
- `gas/` Apps Script web app bound to its own Sheet: cookieless daily counters (`Stats`; hits from crawlers, headless browsers, `navigator.webdriver` and our tests with `octave_notrack=1` go to `Exclus` by reason, as does any hit without `v` (reason `legacy`: the old t.js still cached by crawlers), and `?action=stats` returns `views` counted/excluded/raw) and the January reminder list (`Preorders`). Card checkout: `docs/assets/og-checkout.js` from VREAD-corp/octave-global-checkout (products `dollar-filer-pack-19-usd` / `-29-usd`). Deploy: `cd gas && clasp push -f && clasp deploy -i AKfycbwuvwAEQ_dTI61JJtVUpUUJHFAvp6On3QaF_lS06sO52LZzzfJiSEyt40lVuwABf2FJ -d "..."` (always the same deployment id: the /exec URL is in every page).
- Behaviour counters and A/B: `docs/assets/cro.js` (Octave CRO snippet, vendored byte-identical from octave-checkout `gas/web/jalonel/cro.js`, the Jalonel build with no default host, `data-hosts="dollar-filer.jalonel.com"`; never edit) on every page, after `docs/assets/xp.js` (`OCTAVE_XP`: experiment `price`, variants p19/p19a/p29/p29a, drawn once per tab in sessionStorage, `?v=` forces one) and before `t.js`, which reads `octaveCro.v('price')`. Backend side `gas/src/Cro.js` (also vendored): `track` with `kind:'cro'` → tabs `Comportement`/`Experiences`, `action=cro` summary (key hash in Script Property `CRO_KEY_SHA256`), `cro` block in `?action=stats`.
- `tests/calc.test.mjs` hand-computed cases (`npm test`, which also runs `tests/cro.check.mjs` (octave-checkout's `gas/web/cro.check.mjs` adapted to the Jalonel build) and `tests/cro-gas.check.mjs`); `tests/e2e.spec.mjs` Playwright against the live site at 390 px and 1440 px (`STATS_KEY=... npm run test:e2e`; its last test creates and cancels a live PaymentIntent: add `--grep-invert "live checkout"` to skip it).

Estimates and general information, not tax advice. The paid pack files are not in this repository.
